# 写作与内容设计

## 默认受众与容量

- 默认面向 55–75 岁观众，核心为 60–70 岁；尊重其知识基础、生活经验和判断能力。
- 标准微课 4–5 分钟，加长版 8–10 分钟，引流版 1–2 分钟。
- 1.0 倍速按约 120–160 个有效朗读字符/分钟估算；自然景观为主且用户接受默认值时可用 0.9 倍速。
- 字数只用于容量规划。用户要求精确时长时必须实际朗读或使用其提供的配音数据。
- 字数、速度与时长冲突时列出估算差异，请用户选择优先项。

## 项目表达卡

每个项目确认以下八项：叙述者身份、开场切入点、知识节奏、句子节奏、趣味尺度、观众感受走向、转场方式、结尾方式。

默认叙述者是“见识丰富、愿意分享的老友”。语言以通俗叙述为主，略带书面凝练；短句、中句和必要长句自然交错。专业词首次出现时立即解释，同一句原则上不引入超过两个新专名或数字。

参考样本只用于提取结构、节奏和叙述距离，不作为事实来源。不得复制独特句式、戏剧化现场、夸大承诺或未经核验的案例。

## 共同写作门槛

- 开篇从具体场景、物件、动作、真实反差或可回答的问题进入。
- 全文围绕一个核心问题推进；每段说明它增加了什么信息。
- 场景之后给出机制、因果、对照、人地关系或可执行观察，不连续堆叠形容词。
- 连续三个及以上短句需复核；能自然合并时恢复完整关系。
- 删除聊天填充、论文套话、命令训诫、热梗和宣传腔。
- 不使用“最美、必去、世界第一、百分之百、彻底解决”等超出证据的表达。
- 结尾明确回答开篇问题，并落到知识、观察或行动中的一种。

## 历史文化

主线为“问题或具体场景 → 背景 → 关键变化 → 证据与分歧 → 当下可见线索 → 回答问题”。

- 区分史实、研究解释、传说和后世评价。
- 不替历史人物编造心理、对白、动作或现场反应。
- 建筑、器物和制度不仅描述外观，还解释用途、结构、时代条件和变化。
- 争议问题只写证据能够支持的范围；未关闭的核心争议不得进入发布稿。

## 地理文旅

主线为“空间/路线 → 可见现象 → 形成机制 → 人地关系 → 观察价值”。

- 区域或路线内容沿河流、道路、山脉、高差、边境或季节推进；单点内容围绕核心景观展开。
- 每个地点承担不同功能，避免景点清单。
- 说明自然条件如何影响聚落、建筑、道路、生产或生活方式。
- 用户地点必须全部映射到正文。详写地点至少解释一个经核验的知识点；略写地点至少有一句实质信息。
- 旅行团材料必须移除集合、交通、导游、食宿、购物、自费、费用和抵离说明。

## 生活技能

### 操作技能

采用“困难场景 → 目标结果 → 前置条件 → 操作步骤 → 成功验证 → 常见错误 → 练习”。

- 写清操作对象、入口、动作和完成标志。
- 数字产品核对当前版本；界面不同则给出通用查找关键词。
- 高后果错误优先保留，即使发生频率较低。
- 不承诺“一学就会”或永久解决。

### 生活调适与沟通

采用“综合案例 → 问题识别 → 核心概念 → 实用方法 → 应用示范 → 边界 → 练习”。

- 综合案例不得包含可识别真实个人的组合细节。
- 不贴疾病或人格标签，不把复杂问题归为单一原因。
- 使用“可以尝试”“有助于改善”等与证据相称的表达。
- 区分自行练习、家人协助和需要专业人员介入的边界。

## 内容安全

- 政治、宗教、战争和灾害只做与主题必要的中性说明，不渲染伤害或进行宣教。
- 一般健康常识可以基于权威资料撰写；诊断、治疗、用药、禁忌和个体风险需要合格专业判断。
- 支付、网银和账号安全内容不得索取密码、验证码、证件、银行卡或远程控制权限。
- 普通个人默认匿名；获得授权也只保留完成任务所需的最小字段。
