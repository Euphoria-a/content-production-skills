# UI 模型配方

生成 UI 只作概念参考，不能当作可交付交互界面；生产文字和控件必须用代码实现。

| 标识 | 最适合 | 提示词核心 | 约束与验收 |
|---|---|---|---|
| `mobile-product-screen` | 应用概念 | 完整主屏、系统栏、真实密度、清晰任务层级、一个选中状态 | 无不可读微字、不可能控件或随机功能 |
| `desktop-workspace` | 编辑器与工具 | 完整视口、导航、工具栏、画布或表格、检查器、状态区 | 保持指定工作流和密度，避免泛化卡片网格 |
| `data-dashboard` | 数据分析 | 连贯指标层级、图表家族、筛选、明细表、选中状态 | 数据标签后续代码化，无装饰性无意义图表 |
| `kiosk-touchscreen` | 公共或零售界面 | 大触控目标、短流程、远距可读、真实设备环境 | 对比度可访问，无小控件或桌面端惯例 |
| `device-hero` | 营销展示 | 准确设备透视中的完成 UI、协调背景、清晰产品叙事 | UI 保持独立生产界面，设备不扭曲 |
