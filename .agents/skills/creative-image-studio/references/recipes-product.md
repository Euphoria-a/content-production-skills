# 产品视觉配方

| 标识 | 最适合 | 提示词核心 | 约束与验收 |
|---|---|---|---|
| `clean-catalog` | 电商目录 | 精确产品几何、无缝棚拍背景、柔光箱反射、居中三分之四视角 | 保留参考图 Logo 与形状，不加道具或虚构功能 |
| `campaign-hero` | 落地页或广告主视觉 | 产品为焦点、品牌化环境、受控留白、高级光线层级 | 适合裁切，无伪文案，材质准确 |
| `macro-detail` | 工艺与材料 | 微距裁切、明确表面、掠射光、浅景深但关键细节清晰 | 无融化边缘、错误接缝或多余粒子 |
| `exploded-view` | 部件故事 | 对齐爆炸结构、秩序化间距、清洁透视、技术感精致背景 | 部件数量和连接关系准确，位图中不放标签 |
| `contextual-use` | 使用场景 | 可信互动、人体工学、正确尺度、符合受众的环境 | 身份与参考稳定，手部正确，产品无遮挡 |
