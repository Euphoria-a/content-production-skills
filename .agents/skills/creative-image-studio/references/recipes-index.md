# 90 个提示词配方导航

只读取与当前交付物最相关的一类。每类 5 个配方，共 18 类、90 个配方。

| 分类 | 文件 | 适用内容 |
|---|---|---|
| 摄影写实 | `recipes-photography.md` | 编辑、旅行、生活方式、建筑、食物摄影 |
| 产品视觉 | `recipes-product.md` | 目录图、主视觉、细节图、爆炸图、情境产品图 |
| 包装 | `recipes-packaging.md` | 盒、瓶、标签、礼盒、货架场景 |
| 海报与营销 | `recipes-posters.md` | 中文海报、活动、旅游、发布、公益宣传 |
| 品牌视觉 | `recipes-branding.md` | 情绪板、视觉识别、物料、导视、品牌世界 |
| UI 模型 | `recipes-ui.md` | 移动端、桌面端、仪表盘、自助机、设备展示 |
| 信息图 | `recipes-infographics.md` | 解释图、数据故事、对比、时间线、流程 |
| 技术图 | `recipes-technical.md` | 架构、网络、机械、工作流、系统图 |
| 学术图 | `recipes-academic.md` | 科学图、方法、解剖、图表、教学图版 |
| 地图 | `recipes-maps.md` | 编辑地图、路线、校园、景点、地理故事 |

分类重叠时，以最终交付格式为准。例如产品发布海报归入“海报与营销”，再借用产品视觉中的打光要点，无需加载其他无关分类。
