# 地图配方

生成图用于纹理和地标；准确性重要时，地理几何、路线、名称、图例和比例尺必须确定性实现。

| 标识 | 最适合 | 提示词核心 | 约束与验收 |
|---|---|---|---|
| `editorial-city-map` | 杂志或指南 | 可识别城区结构、地标插画、克制街道纹理、图例区 | 验证位置，标签和路线在 SVG 中 |
| `travel-route-map` | 行程 | 清晰起终点、分段路线、地形线索、重点停靠、叙事方向 | 站点顺序和相对地理准确 |
| `campus-event-map` | 导视 | 简化建筑、入口、无障碍路线、停车与交通区、方向锚点 | 使用已提供平面图，不虚构入口 |
| `regional-food-map` | 主题指南 | 地区轮廓、饮食插画、编辑层级、合集节奏 | 每项对应正确地点，避免刻板印象 |
| `fantasy-world-map` | 虚构世界 | 连贯海岸、地形系统、聚落层级、古旧或现代材质 | 内部地理一致，名称另行提供 |
