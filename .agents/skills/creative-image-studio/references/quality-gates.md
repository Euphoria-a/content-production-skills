# 质量门槛

适用检查未通过前不得交付。

## 结构

- SVG 能作为 XML 解析，宽高为正数，且与 `viewBox` 一致。
- 图层 ID 唯一，并与 `project.json` 一致。
- 所有素材路径位于任务项目内，禁止绝对路径和向上逃逸路径。
- 每个可编辑图层都有位于画布内的有效 `data-bounds`。
- 准确文案保留为 SVG 文本，不含替换字符。
- P0 校验项出现错误时，输出必须视为不合格。

## 位图导出

- 导出尺寸与 SVG 画布一致。
- 输出不是空白或近乎单色。
- 要求透明时必须保留 Alpha。
- 图片没有可见拉伸、错误裁切或边缘杂色。
- 同时导出 100% PNG、JPG 和 25% 预览图；预览图用于移动端扫读检查。

## 视觉检查

- 主体、风格、构图、色彩和用途符合需求。
- 文字层级、对比度、换行、安全区和对齐均有明确设计意图。
- 不含水印、意外文字、重复主体或游离伪影。
- 局部编辑保持身份和全部声明的不变量。
- 一张图最多一个主焦点和一个次焦点，文字区与主体区分离。

## 海报专用门槛

- 读取 `poster-review-checklist.md`，按 `S -> H/T/C -> A -> P -> W/CT/R/A11y` 完成检查；单张海报可跳过 `S`。
- 每张最终图都要在 100% 检查细节缺陷，在 25% 检查层级、行动信息和移动端可读性。
- 校验器警告必须解决，或把代码和理由记录到 `project.json`。
- Logo、组织方、二维码、赞助方、日期、地点或用户文案缺失时，不得悄悄省略；必须请求素材并保留占位。

## 失败处理

- 缺少密钥：指出所需环境变量名，进入顾问模式。
- 能力不支持：选择其他已配置平台或询问用户，不伪造支持。
- URL 过期或无效：明确失败，并保留提示词和响应元数据。
- 渲染器不可用：保留 SVG，并说明需要安装的渲染器。
- 替换失败或生成失败：把相关资产复制到 `assets/_failed/` 并记录 SHA-256，不删除原文件。
