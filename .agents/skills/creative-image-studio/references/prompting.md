# 提示词规范

把需求整理为以下结构中最小但足够使用的字段集合：

```text
用途：<配方分类与标识>
资产类型：<海报、产品图、技术图等>
核心需求：<用户意图>
输入图片：<图片 1：角色；图片 2：角色>
场景或背景：<环境>
主体：<主要对象>
风格或媒介：<摄影、插画、三维、拼贴>
构图与取景：<景别、角度、位置、留白>
光线与氛围：<光线和情绪>
色彩：<颜色名称或十六进制值>
材质与纹理：<表面细节>
逐字文案："<必须完全一致的文字>"
必须满足：<需要保留或加入的内容>
避免出现：<负面约束>
```

## 具体程度

- 用户给出的详细提示词应完整保留，只做结构化整理，不擅自增加内容。
- 对过于笼统的提示词，只补充构图、用途、完成度和有用留白。
- 不虚构品牌、口号、人物、产品或宣传主张。
- 准确文案用引号标出。分层海报要求模型生成无文字底图，文案统一在 SVG 中排版。

## 输入图角色

每张输入图必须标注为：`编辑目标`、`身份参考`、`风格参考`、`构图参考`、`产品参考`、`插入素材` 或 `色彩参考`。多图按编号引用。

## 编辑提示词

先写变化，再重申不变量：

```text
只修改 <区域或图层> 内的 <目标>。
保持 <身份、姿势、几何、光线、色彩、无文字区域> 不变。
不得修改所提供遮罩以外的像素。
```

每次只处理一个变化。保留上一版提示词，只追加本次差异。

## 无文字底图

生成海报底图时必须载入 `assets/anti-text-template.md`。不要在正向提示词里出现“标题”“字样”“标语”“招牌”等容易诱导模型造字的词；改写为“左侧平静留白区”“上方低细节区域”等构图语言。
