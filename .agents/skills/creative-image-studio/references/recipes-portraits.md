# 人物与角色配方

基于参考图编辑时，每次都必须重申身份不变量。

| 标识 | 最适合 | 提示词核心 | 约束与验收 |
|---|---|---|---|
| `editorial-environmental` | 专家或创始人肖像 | 身份稳定面孔、职业相关环境、自然姿态、杂志式照明 | 保留年龄、特征、身体比例和获准服装 |
| `studio-character` | 干净角色设定图 | 全身或四分之三身、清晰轮廓、材质细节、中性可分离背景 | 不裁切、无多余肢体、漂浮道具或文字 |
| `period-costume` | 历史人物 | 时期正确的服装结构、配饰、场景和光源 | 无时代错置或无依据身份主张 |
| `team-ensemble` | 团队视觉 | 清晰不同个体、平衡层级、可信互动、共同照明 | 人数准确、不重复脸、保留角色线索 |
| `identity-scene-edit` | 把人物放进新场景 | 锁定面孔、头发、身体、姿势意图和服装，匹配透视与光线 | 只改指定环境，不发生美化漂移 |
