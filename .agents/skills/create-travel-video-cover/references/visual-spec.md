# 视觉与配置规范

## 优秀参考样例

本公开包不包含原项目参考封面。若维护者拥有可公开分发的样例，可放入 `assets/reference/`；否则以本文件的数值规范和验收规则为唯一依据。不得从固定本机路径读取未随 Skill 分发的素材。

## 固定视觉参数

| 元素 | 参数 |
|---|---|
| 画布 | 1024×1365 px，3:4 竖版 |
| 中央锐利图 | 1024×576 px，16:9，y=394（整数居中） |
| 模糊填充 | 同一中央图覆盖画布，高斯模糊 60px，亮度 0.82 |
| 顶部渐变 | 高度 320px，冷底色 `(6,10,18)`，最大 alpha 155 |
| 底部渐变 | 高度 490px，冷底色 `(6,10,18)`，最大 alpha 225 |
| 主标题 | 文悦新青年体简体 W8，162px，纯色 `#FFD700` |
| 副标题 | 同字体，135px，纯色 `#FFD700` |
| 正文 | 同字体，76px，纯色 `#FFFFFF` |
| 主副标题间距 | 10pt，约 54px |
| 正文行距 | 2pt，约 11px |
| 正文底留白 | 30px |
| 图文间距 | 约 28px |

标题区从 y=58 开始。主副标题使用 10pt 行距，在当前画布字号比例下取 54px；正文仍使用 2pt、约 11px。中央图 y 取 `(1365-576)//2 = 394`。

## 禁止的文字效果

所有标题和正文只画一次纯色填充：

- 不使用 `stroke_width`、`stroke_fill` 或 Pillow 的其他描边参数。
- 不使用文字阴影、外发光、浮雕或重复偏移绘制。
- 不使用“大字号深色文字铺底，再覆盖小字号彩色文字”的模拟描边方案。
- 不因商业字体在描边时出现错位而换用另一种描边方法；正确处理是完全取消描边。

## 字体

优先通过系列 JSON 的 `font` 字段提供已授权字体路径，也可设置环境变量 `TRAVEL_VIDEO_COVER_FONT`，或把已授权字体放在 `assets/fonts/`。本仓库不分发商用字体。找不到字体时停止并报告，不要静默换成其他字体；只有用户明确同意时才使用替代字体并重新验收。

## 背景图

- 使用横向 16:9 图，源图裁切区域至少 1024×576；中央锐利区不得上采样。
- 主体放在中央安全区，避免依赖边缘细节；画面任何位置都不得出现文字、标识、水印、角标、Logo或无关人像特写。
- 提示词用 2 至 3 句简短中文自然语言，先写地点或对象，再写景观、光线、季节和横向构图，最后明确写“画面中不要出现任何文字、AI生成标识、水印、角标或Logo”。
- 生成工具支持尺寸时请求 1536×864；生成后检查实际像素。
- 不写英文 `Scene/Subject/Style/Constraints/Avoid` 等结构化字段。
- 生成后以原始分辨率查看背景，依次检查右下角、左下角、右上角、左上角、中央与全部边缘。发现“AI生成”“AI生成图片”、生成平台名称或图标、签名、水印、Logo、角标及其他文字时，立即废弃并重新生成或更换素材。
- 不得依赖中央裁切避开标识，因为同一背景还会被放大到上下模糊延伸区；也不得用渐变、模糊、正文或色块遮盖标识。

## 系列 JSON 配置

```json
{
  "series_name": "印度",
  "output_root": "output",
  "font": "path/to/your-authorized-font.otf",
  "covers": [
    {
      "episode": 1,
      "subtitle": "寺院与菩提",
      "body": [
        "跟着玄奘继续往前走，",
        "来到那烂陀古老寺院，",
        "看看佛法怎样传到远方，",
        "也找到这段旅程的起点。"
      ],
      "background": "work/ep01/background-16x9.png",
      "background_verified_no_text": true
    },
    {
      "episode": 2,
      "subtitle": "圣河与夜祭",
      "body": [
        "沿着恒河慢慢走下去，",
        "来到瓦拉纳西的河岸，",
        "看看灯火怎样照亮夜色，",
        "也读懂信仰留下的日常。"
      ],
      "background": "work/ep02/background-16x9.png",
      "background_verified_no_text": true
    }
  ]
}
```

相对路径以配置文件所在目录为基准。脚本自动完成以下操作：

1. 检查主标题一致、副标题字数与连接格式一致。
2. 检查正文为四行、每行不超过 15 字、前三行逗号且末行句号。
3. 要求每集显式填写 `background_verified_no_text: true`，表示已按原尺寸确认背景无任何非设计文字或标识；缺失或为其他值时拒绝执行。
4. 在 `<output_root>/<series_name>系列视频封面/` 中生成 `XX第一集封面.png/.jpg` 等文件。
5. 按集数排序并生成 `<series_name>系列缩略图.jpg`。

## 系列缩略图

- 1 集使用 1 列；2 至 4 集使用 2 列；5 至 8 集使用 4 列，更多集数继续使用 4 列换行。
- 顶部使用冷深蓝标题栏和纯金黄色系列标题，不加描边或阴影。
- 页面使用浅暖灰背景，每张封面保持 3:4 比例，不拉伸。
- 每张封面下方显示两位集数和副标题，如 `01 寺院与菩提`。
- 缩略图顺序必须与 `episode` 一致，不能按文件名的偶然排序决定。

## 视觉验收重点

- 主副标题位于中央图上方，正文位于中央图下方；图上不显示章节号。
- 标题、副标题和每行正文分别水平居中；正文末位标点不计入居中宽度，使标点悬挂在右侧。
- 所有文字边缘保持字体原始形状，不得出现描边、阴影、黄色矩形、笔画消失或双层错位。
- 除主标题、副标题、四行正文和缩略图说明外，整张图片不得出现其他文字；重点检查中央图右下角和上下模糊延伸区是否出现“AI生成”、平台名称、水印、角标或Logo。
- 中央图必须锐利，上下延伸必须明显模糊；不能把 3:4 图直接全屏铺满。
- 系列缩略图必须包含全部封面，留白、列宽、间距和图下说明保持一致。
