# 文旅视频封面生成

把视频内容转化为文字连贯、系列统一、可直接交付的视频封面。先完成整套文字设计，再准备背景、批量合成、生成系列缩略图并目视验收。

## 执行流程

1. 提取系列名、集数、各集主题、主要地点或事件、背景图来源和输出根目录。信息不足以判断本集叙事方向时，只补问会改变封面内容的缺项。
2. 阅读 [copy-rules.md](references/copy-rules.md)，为整套系列一次性设计副标题与四行正文。先检查所有副标题的字数和格式统一，再检查每篇正文连读通顺。
3. 以用户提供的旁白、提纲和资料为创作素材，不做逐行对账，也不强行覆盖全部地点或知识点。只保留最适合构成叙事弧线的内容；不要凭空添加会改变事实含义的信息。
4. 阅读 [visual-spec.md](references/visual-spec.md)。若 `assets/reference/` 中存在经授权的样例，可额外参考其构图与系列缩略图布局；若不存在，只按数值规范执行，不得读取本机其他项目目录中的样例。
5. 准备一张至少 1024px 宽、可裁为 16:9 且中央主体完整的背景图。需要生成时使用可用的图像生成工具，以 2 至 3 句中文自然语言说明地点、主要景观、光线或季节和横向构图，并明确要求“画面中不要出现任何文字、AI生成标识、水印、角标或Logo”；工具支持尺寸时请求 1536×864。
6. 以原始分辨率打开每张背景，检查四个角、中央主体和全部边缘。发现“AI生成”“AI生成图片”、平台标识、水印、Logo、角标或其他非设计文字时，废弃该素材并重新生成或更换；不得用裁切、渐变、模糊或正文覆盖来掩盖。
7. 按 [visual-spec.md](references/visual-spec.md) 建立整套系列 JSON 配置。只有完成上述检查后，才为该集填写 `"background_verified_no_text": true`。运行 `scripts/build_cover.py --config <config.json>`，先用 `--dry-run` 检查机械约束，再正式生成。
8. 逐张打开成品，再打开系列缩略图检查整套一致性。脚本通过不代表叙事已经通顺，也不代表视觉已经验收。

## 文字硬规则

- 主标题固定为系列国家或地区名，同一系列不得变化。
- 副标题概括本集主题；整套系列的副标题必须采用相同字数和相同格式，如全部使用五字的“A与B”结构。
- 正文正好 4 行，每行含标点不超过 15 个字符，不设强制总字数上限。
- 四行采用“动作 → 地点 → 观察 → 主题收束”的叙事弧线。允许一个语义成分跨两行，但断行必须符合语义停顿。
- 前三行使用 `，` 连接，第四行用 `。` 收束。去掉换行后，四行必须成为一段口语化、语法完整、前后连贯的完整句子。
- 不要求每行成为独立信息单元，不做地点或知识点逐项对账，不为覆盖内容而牺牲通顺度。
- 使用自然口语，像见识丰富的老友带观众往前走；避免景点清单、名词堆砌、硬凑金句和生硬书面语。
- 删除宣传口号、网络热梗、说教语气和“最美、必去、世界第一、怎么拍都好看”等表达。
- 输出前扫描乱码、替换字符、异常问号和被破坏的地名或专名。

## 视觉硬规则

- 所有文字只使用纯色填充，禁止描边、阴影、外发光、浮雕及任何模拟描边方式。
- 禁止通过“大字号深色底层＋小字号彩色上层”制造边缘效果。Pillow 的 `stroke_width` 和 `stroke_fill` 参数也不得使用。
- 除本技能主动绘制的主标题、副标题、四行正文和系列缩略图说明外，整张图片不得出现任何文字；尤其禁止出现“AI生成”“AI生成图片”、生成平台名称、水印、角标或Logo。
- 主标题和副标题的行间距为 10pt，对应本画布约 54px；正文行间距仍为 2pt、约 11px。
- 画布、中央图、模糊延伸、渐变、字体与字号按 [visual-spec.md](references/visual-spec.md) 执行。

## 合成命令

```powershell
python scripts/build_cover.py --config path/to/series-config.json --dry-run
python scripts/build_cover.py --config path/to/series-config.json
```

若默认 Python 缺少 Pillow，切换到已有 Pillow 的环境或安装依赖；未成功运行并验收时，不得声称成品已经完成。

## 成品验收

- 确认每张封面为 1024×1365，中央锐利图为 1024×576 且未上采样，上下使用同图模糊延伸。
- 确认主副标题为纯金黄色、正文为纯白色，所有文字都没有描边和阴影。
- 确认正文正好 4 行、每行不超过 15 字；逐篇朗读去除换行后的完整句，修正任何卡顿、跳跃或逻辑断裂。
- 确认叙事顺序能识别出动作、地点、观察和主题收束，不把四行写成四条互不相干的清单。
- 确认整套副标题字数、连接方式和语法结构一致。
- 确认图上没有集数、章节号、来源、Logo 或额外说明。
- 以原始尺寸检查中央图片右下角及其余三个角，再检查上下模糊延伸区；确认整张单集封面和系列缩略图都没有“AI生成”或任何非设计文字、平台标识、水印和角标。
- 确认每张封面的 PNG 与 JPG 均正常，并检查系列缩略图没有漏图、错序、拉伸或裁切。

## 交付结构

把全部成品图片集中放进一个文件夹；配置、提示词和背景素材留在工作目录，不进入最终交付文件夹。

```text
<输出根目录>/
└── 印度系列视频封面/
    ├── 印度第一集封面.png
    ├── 印度第一集封面.jpg
    ├── 印度第二集封面.png
    ├── 印度第二集封面.jpg
    ├── ……
    └── 印度系列缩略图.jpg
```

系列完成后逐集列出副标题、四行正文、各行字数和验收状态，并单独确认系列缩略图已经生成。
