# 视觉硬约束

所有像素坐标以 1024×1536 画布左上角为原点；机器可读值见 [layout.json](layout.json)。

## 图层顺序

1. 明亮的真实背景拼贴
2. 仅主标题区允许无边框羽化明暗调整；副标题区不允许任何底色补偿
3. 用户人物透明层
4. 品牌、主副标题
5. 嘉宾卡、时间地点卡、图标和正文

## 标题

- 主标题：文悦新青年体 W8，160px，字距 4px，最多两行，不自动缩字。
- 输入为两段标题时，先去掉段间换行并尝试合并；160px、4px字距下总宽不超过864px时必须使用单行，禁止为了维持双行而人为拆分。
- 双行标题视觉顶端固定为 y=175、355；单行标题固定为 y=215。
- 双行标题的副标题中心位于 y=598；单行标题的副标题上移，中心位于 y=460。
- 副标题上下均不绘制横线、分隔线或装饰线。
- 主标题末行可见底部与副标题文字可见顶端至少间隔40px；脚本按实际字体边界校验。
- 主标题与副标题分别从以下颜色中选取局部对比度最高者：
  - 暖白 `#F6F1E5`
  - 深青 `#043337`
  - 金色 `#E0B153`
  - 藏蓝 `#173A5E`
- 主标题对比度至少 3:1；副标题至少 4.5:1。
- 主标题对比度不足时允许做无边框羽化明暗调整。
- 副标题必须直接叠加在自然背景上；禁止黑色、深青色、白色或半透明长条底板，也禁止用横向明暗渐变制造底带。四色均无法达到4.5:1时重新规划背景，不得自动加底。
- 副标题区低于亮度100的暗像素占比超过72%，且比上下邻区暗超过28时，脚本判定为人为深色横带并拒绝输出。

## 品牌与卡片

- 品牌板：`(35,50)-(470,112)`，填充 70% 不透明度，2px 边框；默认深青底金边，用户明确要求浅色卡片时可切换为浅砂底棕边。
- 品牌文字：Noto Serif CJK Bold 36px，在底板中水平、垂直居中。
- 嘉宾卡：`(522,970)-(980,1360)`，填充 70% 不透明度，2px 边框；与品牌板使用同一卡片主题。
- 时间地点卡：`(522,1377)-(980,1498)`，与嘉宾卡同样式。
- 右下文字块左右各留 26px，整体在卡片中上下平衡；正文保持左对齐。
- `分享嘉宾｜姓名` 与 `核心内容` 均为 34px。
- 嘉宾身份、简介与核心内容均为 27px，正文行步进均为 38px。
- `课程时间｜` 与 `课程地点｜` 标签均为 27px；两个值也均为 27px。
- 时间行图标、标签和值共享圆心 y=1410；地点行共享圆心 y=1463。文字按实际可见字框垂直居中，不得用字体基线或视觉顶端替代圆心。

## 两行与三行结构

- 嘉宾正文由一行身份和一至两行简介组成：
  - 三行位置：y=1040、1078、1116。
  - 两行位置：y=1059、1097。
- 核心内容：
  - 三行位置：y=1238、1276、1314。
  - 两行位置：y=1257、1295。
- 两行版保持 38px 行距，并在三行区域内垂直居中。

## 背景与亮度

- 背景必须是 1024×1536，禁止脚本自动裁切或拉伸。
- Rec.709 平均亮度必须在 145–200；25% 分位亮度不得低于 90。
- 标题区保持低对比但不得空白；允许真实建筑、山体、冰川、街区或自然纹理作为中远景穿过标题区。
- 至少一组清晰可辨的地点素材必须进入 y=80–650；禁止把全部素材堆在 y>650 的中下部。
- 上半区 y=0–688 的亮度标准差不得低于 18，边缘结构均值不得低于 2.5；卡片区仍禁止出现文字、脸、铭牌和强光。
- 顶部 y=0–344 横向四等分后，每栏亮度标准差不得低于 8、边缘结构均值不得低于 1；禁止只在单一区域堆放素材来骗过整体密度检查。
- y=0–688 内相邻整行或整列的平均亮度突变不得超过 20；超过时视为贯穿式硬接缝或矩形拼贴边界并拒绝输出。
- 背景不得有重复地标、复制/镜像块、拉丝像素、透视断裂或大面积人物移除补洞；至少一项实际背景来源必须是不含人物的干净真实地点照片。
- 地标优先放在上半部偏右或跨越上中部，不得压住标题、副标题和人物脸部。

## 人物

- 人物层必须是 1024×1536 RGBA 透明 PNG。
- 主体固定左下，最右可见像素不得超过 x=510，必须触底 y=1536；人物与 x=522 开始的嘉宾卡之间保留安全间隔。
- 人物左侧至少保留 12px 透明安全边距；顶部和右侧不得接触画布边缘。
- 头顶建议位于 y=600–720；不透明面积不得超过画布 28%。
- 脸部中心约为 `(300,770)`，允许 ±20px；脸框高度 190–220px。脸部项目必须通过放大人工检查。
- 人物层不得含照片背景、Logo、品牌、活动文字、水印或边缘色溢。
- 人脸锚点和脸框大小优先；不得为了显示完整全身而缩小人脸。
- 全身照等比缩放并定位后，允许画布下边界裁掉超出的腿部、裤脚或衣服下摆；裁切只能发生在 y=1536 底边，左、右、上方不得新增裁切。
- 头发、脸、耳朵、双肩、上半身、手臂、手指和主要随身物品必须清晰保留。原图本身已有的截断保持原状，禁止补造身体。
- 肩膀、衣领、衣袖和躯干实体区域必须保持清晰、不透明且边界连续；禁止虚化、雾状软边、半透明侵蚀、生成式溶解或缺口。硬质衣物边缘的透明过渡不得宽于 3px，头发细丝除外。
- 自动分割只可生成粗蒙版；最终蒙版必须在原图分辨率分区精修，并完成 1–2px 前景边缘去色污染。硬质衣物边缘只允许 0–1px 抗锯齿，不得残留天空蓝、草木绿、砖瓦红、白色或暗色轮廓。
- 最终缩放必须使用预乘透明度重采样且只执行一次；禁止普通 RGBA 反复缩放造成颜色串边。
- 人物全部非零透明像素中，alpha 1–15 的微弱残留不得超过 2%；alpha≥16 的可见人物像素中，alpha 16–249 的过渡像素不得超过 15%。超过时视为残留背景或过度羽化并拒绝输出。
- 与内侧不透明前景相比，半透明边缘中颜色距离超过50或亮度差超过35的像素占比不得超过12%；超过时视为背景色污染或普通RGBA缩放串色并拒绝输出。
- 若底边裁切会破坏头部、肩膀、上半身、手或主要道具，停止并询问用户。

## 固定验收

- 最终尺寸、背景亮度、人物透明范围和文本宽度由脚本自动检查。
- 人物身份、底边裁切范围、头发/耳侧/肩线/袖线/手指的 400% 边缘质量、脸部锚点、品牌清理、史实、顶部四栏素材分布、背景接缝/复制/拉丝、地标遮挡和四角伪文字必须人工放大检查。
- 任一固定项失败即停止，不得交付近似版本。硬约束不接受“本地放宽”或推定用户授权。
- 只能运行 Skill 目录中的正式 `scripts/render_poster.py`，禁止复制、改名或在工作目录创建 `render_local.py`。
- 成品必须再通过正式 `scripts/validate_poster.py` 的来源校验与独立重渲染比对；缺少 `verification-report.json` 或状态不为 `passed` 时不得交付。
