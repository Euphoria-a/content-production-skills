# 背景素材检索与拼贴

## 素材优先级

1. 用户提供且明确允许使用的照片。
2. 公共领域、开放许可或可商用许可清楚的真实照片。
3. 政府、文旅部门、博物馆、景区官网、UNESCO 等可信页面中的构图与史实参考。
4. 缺少真实古代元素时，依据可信史料用 AI 生成局部元素。

许可、地点或史实不明确时，先询问用户。禁止把带水印、来源不明或版权状态不清楚的图片直接拼入成品。

## 来源记录

为每张最终使用的真实素材记录：

- 网页或本地文件路径
- 地点和元素名称
- 作者或机构（如有）
- 许可或用户授权说明
- 在拼贴中的用途
- 原素材是否含人物：`contains_person: true | false`

把记录写入文案 JSON 的 `background_sources`；渲染器会在本期工作目录强制生成 `background-sources.json`。默认不作为最终交付物发送，但必须保留。

至少一张作为实际背景使用的真实地点照片必须 `contains_person: false`。含嘉宾或其他人物的原照片只能用于构图参考，或截取完全未受人物影响的局部；不得作为唯一背景来源，不得靠大面积生成式填充擦除人物后充当主背景。找不到干净地点素材时先询问用户。

## 构图保留区

- 主标题区：x=80–944，y=150–525；保持低对比和可读性，但不得用空白、纯色或只有渐变的大片区域代替真实素材。
- 副标题区：单行标题时为 x=132–892、y=412–508，双行标题时为 x=132–892、y=550–646；保持自然、连续的背景明暗，不得加入任何横向黑色、深青色、白色或半透明底带。
- 人物区：x=0–535，y=600–1536；不得放置必须完整展示的地标。
- 卡片区：x=510–995，y=950–1510；避免强光、文字、脸和建筑铭牌。
- 地标区：至少一组地点元素进入 y=80–650，优先上半部偏右或跨越上中部；不得全部堆叠在人物头部以下。

## 上半部画面密度

- 先确定上部、中部、下部三个素材锚点，再进行拼贴；上部锚点位于 y=80–350，中部锚点位于 y=350–700。
- 把最能识别地点或课程主题的建筑轮廓、山脊、冰川、街巷、树冠或历史构件上移，使其进入标题周围的中远景。
- 标题正后方降低局部对比度，不得把素材整体下移来换取可读性。
- 禁止出现“顶部只有天空或纯色、全部建筑与景观集中在中下方”的构图。
- y=0–344 横向分为四栏，每栏都必须有自然亮度层次和真实结构细节；可降低对比度，但不得用大块纯色、模糊矩形或简单渐变占位。
- 渲染器会检查 y=0–688 的整体层次、顶部四栏密度和贯穿式硬接缝；不合格时重新规划背景，不得用噪点或伪文字骗过检查。

## 拼贴连续性

- 背景必须保持单一可信视角、尺度、透视和光线方向；不同照片只允许通过自然遮挡、景深和柔和局部蒙版衔接。
- 禁止水平或垂直硬接缝、矩形补丁、拉丝像素、复制块、镜像块、重复树木、重复亭台和建筑断层。
- 同一主地标不得在画面中复制出现两次；确需历史与现实对照时必须使用明确不同的素材和层级，并先取得用户确认。
- 禁止把人物原照片中的背景放大、重复、拉伸或大面积生成式补洞来填满画布。人物遮挡面积较大时，改用另一张干净真实地点照片。

## 课程主题映射

- 城市史：真实当代城市与历史街区分层拼贴；古代建筑缺少可信照片时才生成复原元素。
- 自然地理：突出真实地貌、季节和尺度，不添加不存在的建筑或动物。
- 导游与表达课程：地标退居中远景，把标题和人物作为主层级。
- 摄影课程：使用真实光线、观察路径和代表性机位，避免虚构器材或极端特效。

## 背景提示词硬句

在背景生成或编辑提示词开头写明：

`固定模板纯背景：制作明亮、自然、真实照片质感的1024×1536竖版地点拼贴；至少一组可识别的地点素材进入y=80–650，画面上部、中部、下部均有真实视觉元素，y=0–344横向四栏均保持自然结构和亮度层次，禁止把素材全部堆在中下方，标题后方只降低对比度不得留成纯色空白；副标题区域必须保持自然背景连续，不得添加黑色、深青色、白色或半透明横向长条，不得制作明暗底带；保持单一可信透视与光线，禁止水平或垂直硬接缝、矩形补丁、拉丝、复制、镜像、重复地标和大面积生成式补洞；不得出现任何人物、文字、字符、品牌、活动标识、Logo、水印、卡片、边框、图标或界面元素；左下人物区和右下卡片区必须保留。`

## 检查

- 读取自动亮度审计；不达标时先调整曝光和局部层次。
- 检查副标题上下是否出现水平直边、整行变暗或整行变亮；发现底带时恢复自然背景并重新选字色。
- 沿 y=0–688 检查贯穿画面的水平/垂直直边；检查同一建筑、树木、亭台是否被重复、镜像或拉伸，检查人物移除区是否出现模糊拉丝和矩形补丁。
- 放大四角和所有建筑标牌，清除文字、Logo、水印和伪字符。
- 对照来源确认地标、时代和形制；无法确认时询问用户。
