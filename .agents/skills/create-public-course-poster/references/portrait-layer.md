# 人物透明层规范

## 编辑范围

使用用户提供的原照片，只执行：

- 抠图与透明背景
- 清除照片背景、品牌、活动文字、Logo 和水印
- 清除服装或道具上可识别的品牌活动内容
- 去白边、去色溢，并只对硬边做 1–3px 抗锯齿；禁止整片羽化人物
- 统一色温、曝光、锐度和轻微噪点
- 缩放并定位到固定左下区域

先把原照片与抠图结果并排放大，列出原图中所有可见部位和物品；抠图后逐项确认。全身照还要标记预计落在画布底边之外的下半身范围。

## 精修流程

1. 在原照片分辨率生成粗蒙版；U2Net、rembg、通用分割模型或图像编辑模型的首次结果只能作为起点。
2. 分区精修蒙版：
   - 头发、耳侧：保留原图真实轮廓和可见发丝，不得把头发切成光滑头盔状，也不得生成原图没有的发丝。
   - 双肩、衣领、衣袖、躯干、衣摆：使用清晰硬蒙版，实体边缘只保留 0–1px 抗锯齿，禁止羽化。
   - 手和手指：逐指检查缝隙、袖口和肤色边缘，不得粘连或缺指。
3. 做前景去色污染：沿头发、耳朵、肩线和袖线向内处理 1–2px，去除原背景造成的白边、天空蓝边、草木绿边、砖瓦红边和暗色描边；不得用整体腐蚀人物轮廓代替去污。
4. 保持人物内部 RGB 来自原照片，只修改 alpha 蒙版和必要的 1–2px 边缘颜色；禁止重绘脸、头发、衣服和手。
5. 精修完成后使用 Skill 内置 `scripts/prepare_portrait.py`，按源脸框一次性完成预乘透明度缩放与定位；禁止普通 RGBA 反复缩放导致边缘串色。

禁止生成新脸、新服装、新发型、新姿态、新道具或补造身体。
禁止剪掉或虚化原图中可见的头发、耳朵、肩膀、上半身、手臂、手指、相机、背包或主要随身物品。全身照按固定脸框缩放后，只允许由画布 y=1536 底边裁掉超出的腿部、裤脚或衣服下摆。

## 输出

- PNG、RGBA、1024×1536。
- 除人物外完全透明。
- 左侧至少保留 12px 透明安全边距；顶部和右侧不得触边。
- 最右可见像素不超过 x=510；不得进入从 x=522 开始的嘉宾卡区域。
- 主体必须触底；头顶建议 y=600–720。
- 不透明面积不得超过画布 28%。
- 脸部中心约 `(300,770)`，脸框高度 190–220px。
- 全身照先锁定脸部中心和脸框高度，再让超出的下半身自然落到画布底边之外；不得缩小人脸来迁就全身完整显示。
- 肩膀、衣领、衣袖和躯干实体区域保持清晰且基本不透明，不得出现雾状软边、半透明侵蚀或溶解缺口；硬质衣物轮廓的透明过渡不超过 3px，头发细丝除外。
- 不得残留原背景造成的白边、亮边、暗边或彩色描边；渲染器会输出 `portrait-proof.png`，分别在白色、棋盘格和深青底上显露边缘污染。
- 全部非零透明像素中 alpha 1–15 的微弱残留不超过 2%；alpha≥16 的可见像素中 alpha 16–249 的过渡像素不超过 15%。
- 半透明边缘与其内侧不透明前景相比，颜色距离超过50或亮度差超过35的像素占比不超过12%；该指标用于拦截白边、天空蓝边、草木绿边、砖瓦红边和普通RGBA缩放串色。
- 放大测量可见脸部边界，并把 `[左, 上, 右, 下]` 写入文案 JSON 的 `portrait_face_box`；不得用头发外轮廓或整颗头部替代脸框。

## 图像编辑提示词硬句

`只编辑这张用户人物照片：完整保持同一人的脸、五官、真实发型、服装、姿态和随身物品，不得生成或补造身体；先在原始分辨率移除全部照片背景、品牌、活动文字、Logo与水印，一键分割结果只能作为粗蒙版；分别精修真实头发与耳侧、双肩与衣领、衣袖与手指、躯干与衣摆，深色头发和衣服边缘必须去除原背景造成的白边、亮边、天空蓝边、草木绿边、砖瓦红边和暗边，只允许向内处理1–2px边缘颜色，不得整体腐蚀人物；肩膀、衣领、衣袖和躯干必须清晰连续且保持实体不透明，硬边只保留0–1px抗锯齿，禁止模糊、雾状羽化、半透明侵蚀、生成式溶解或缺口；如果原图是全身照，最终只允许由画布y=1536底边裁掉超出的腿部、裤脚或衣服下摆，不得切掉头发、脸、耳朵、双肩、上半身、手和主要道具；不得生成新人物、不得改脸、不得换衣、不得添加文字或背景。`

## 验收

1. 在 `portrait-proof.png` 的白色、棋盘格、深青底和单独透明度通道上，以 100% 检查整个人物；不得缩小检查图来判断边缘质量。
2. 在 `portrait-edge-proof.png` 中以 400% 检查头发/耳侧、双肩/衣领、双臂/袖口和手指；任一底色出现 1px 以上连续描边、锯齿、色溢或背景残片即重新精修。
3. 放大检查面部与原照片一致。
4. 把原图和透明层并排，确认新增裁切只位于画布 y=1536 底边且只涉及允许的下半身范围；左、右、上边新增裁切一律判失败。
5. 检查肩膀、衣领、衣袖和躯干没有模糊、雾状软边、半透明侵蚀、溶解缺口；任一出现即判失败并重新抠图。
6. 检查服装、道具和残留背景中无品牌活动内容。
7. 对照调试网格检查脸部中心、脸框高度、头顶、左侧安全边距、右边界和触底关系。
8. 若固定脸框会迫使底边裁到头部、肩膀、上半身、手或主要道具，询问用户或要求更换照片。
