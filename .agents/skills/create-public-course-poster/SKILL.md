# 制作“区域文化 / 世界文化”固定海报

只改变本期人物、地点、课程文案和背景素材；固定画布、坐标、字体、字号、字距、卡片和品牌规则。默认使用深青卡片；只有用户当次明确要求浅色卡片时，才允许使用受限的 `light_sand` 卡片主题，坐标、透明度和品牌文字不变。遇到地点归属、史实、人物清理或素材许可不明确时，先询问用户，不得猜测。

## 开始前

1. 完整阅读：
   - [模板字段](references/template-fields.md)
   - [视觉硬约束](references/visual-locks.md)
   - [背景素材与拼贴](references/background-research.md)
   - [人物透明层](references/portrait-layer.md)
2. 检查用户是否提供嘉宾照片、嘉宾姓名、课程时间、课程地点、背景地点和课程资料。
3. 使用具备 Pillow 的 Python 环境；记录实际 Python 与 Pillow 版本，未成功运行时不得声称完成。
4. 阅读 `assets/fonts/README.md`。主副标题必须使用用户自行提供且具备相应授权的文悦新青年体；本公开包不分发该付费字体。其余字体可由用户提供 Noto CJK，或由脚本从常见系统字体中解析。

## 固定品牌

- 中国地点：`区域文化 · 网络公益课`
- 中国以外地点：`世界文化 · 网络公益课`
- 地点归属不明确：停止并询问用户。

品牌文字、栏目名、字体、颜色候选和布局由脚本固定，禁止写成用户可覆盖的 JSON 字段。

## 工作流程

1. 从材料中整理字段并标记来源。事实不清楚时先询问，不补写经历、奖项、数字或史实。
2. 核验背景地点并解析为 `location_scope: china | world`。严格区分背景地点与课程地点。
3. 按 [背景素材与拼贴](references/background-research.md) 检索真实素材：优先用户素材、公共领域或许可清楚的网络照片；记录来源。真实古代元素缺失时，才允许依据史料用 AI 补充。
   - 至少使用一张不含人物的干净真实地点照片；含嘉宾的原照片不得作为唯一背景来源，也不得靠大面积擦除人物后扩展成主背景。
4. 制作 1024×1536 的纯背景 PNG：无人物、无文字、无品牌、无活动标识、无卡片、无水印、无伪字符；为标题、人物和右下卡片预留区域。
   - 把至少一组可识别的地点素材上移到 y=80–650；标题区降低对比度但不得空白，禁止把全部素材堆在中下方。
   - 检查顶部四栏均有自然结构，且无水平/垂直硬接缝、矩形补丁、拉丝、复制块、镜像块、重复地标或透视断层。
   - 副标题直接使用自然背景；禁止添加黑色、深青色、白色或半透明横向长条，也禁止预先压暗或提亮成长带。
5. 使用图像编辑工具处理用户原照片：
   - 只做抠图、品牌活动内容清除、色温明暗统一和固定位置调整；一键抠图、U2Net、rembg 或其他分割模型的首次输出只能作为粗蒙版，禁止直接进入排版。
   - 在原照片分辨率完成二次精修：头发与耳侧单独做精细蒙版，肩膀、衣领、衣袖、手指和衣摆逐段修边，并对原背景造成的亮边、暗边和彩色溢出做前景去色污染。
   - 精修后只运行 `scripts/prepare_portrait.py` 做一次预乘透明度缩放和固定定位；禁止用普通 RGBA Lanczos 反复缩放人物层。
   - 禁止生成新脸、新服装、新发型、新姿态或补造人物身体。
   - 先按可见脸框等比缩放并定位，使脸部中心和大小满足固定锚点；不得为了保全全身而缩小人脸。
   - 全身照允许画布下边界裁掉超出的裤脚、腿部或衣服下摆；除画布底边外，禁止新增裁切。头发、脸、耳朵、双肩、上半身、手臂、手指和主要随身物品必须清晰保留。
   - 肩膀、衣领、衣袖和躯干不得出现虚化、雾状软边、半透明侵蚀或溶解缺口；仅头发细丝允许保留自然的细微透明过渡。
   - 输出 1024×1536 透明 PNG；主体位于左下并符合人物层规范。
6. 把原照片、透明人物层和透明度通道并排放大检查。必须以 100% 查看整个人物，并以 400% 分别查看头发/耳侧、双肩/衣领、双臂/手指；除允许位于画布底边的下半身裁切外，发现新增缺口、平直切边、锯齿、亮色描边、暗边、彩色溢出、肩膀虚化、半透明侵蚀、部位或道具缺失时，重新编辑；不得进入排版。
7. 按模板字段创建 UTF-8 JSON。填写经放大测量的 `portrait_face_box` 和全部 `background_sources`；核心内容先按换行及逗号、句号、分号等拆分，最终删除标点，保留两至三条。
8. 只运行当前 Skill 目录中的正式脚本；禁止复制、改名、修改校验函数或在工作目录创建 `render_local.py`：

   ```powershell
   & <工作区Python> <Skill目录>\scripts\render_poster.py `
     --base <1024×1536背景PNG> `
     --portrait <1024×1536透明人物PNG> `
     --data <文案JSON> `
     --out <最终PNG> `
     --debug-overlay
   ```

9. 运行正式独立验证器：

   ```powershell
   & <工作区Python> <Skill目录>\scripts\validate_poster.py --poster <最终PNG>
   ```

10. 检查脚本生成的 `<文件名>_work/`：
   - `layout-manifest.json`
   - `audit-report.json`
   - `debug-overlay.png`
   - `portrait-proof.png`，在白色、棋盘格和深青底上检查人物边缘
   - `portrait-edge-proof.png`，按原始像素放大检查头发、肩线、衣袖和手部
   - `background-sources.json`
   - `verification-report.json`，且 `status` 必须为 `passed`
11. 放大检查成品四角、人物脸部、标题、副标题、嘉宾卡和时间地点卡。逐字核对姓名、履历、日期、时间和地点。
12. 默认只向用户交付最终 PNG；内部工作文件保留用于复核。

## 背景与人物的边界

- 背景只决定地点、时代、地貌和课程主题氛围。
- 人物只能来自用户照片；不得把人物交给模型重新生成。
- 人物固定左下，背景拼贴必须主动避开人物保留区；不得为保住地标而自由移动人物。
- 原照片中的所有品牌、活动文字、Logo、水印和活动背景不得进入新海报。
- 人物照片中的景区背景不得随人物层进入海报；不得用同一张含人物照片的大面积补洞结果充当主背景。

## 文案与排版失败

- 脚本不自动缩小主标题、副标题和信息卡字号。
- 文字超宽时压缩文案，再重新渲染。
- 核心内容不足两条、超过三条或无法可靠总结时，先询问用户。
- 主标题四色经过局部羽化调整后仍无法达标时停止；副标题四色无法直接达到4.5:1时重新规划背景，禁止添加底带。
- 人物层优先满足固定脸部尺度和锚点；全身照超出画布时只允许在画布底边裁掉下半身或衣服下摆，禁止从左、右、上方裁切人物。
- 若底边裁切会切到头部、肩膀、上半身、手、主要道具，或仍无法满足占画比例和背景保护，停止并询问用户或要求更换照片。

## 禁止事项

- 禁止输出非 1024×1536 文件或自动裁切错误尺寸输入。
- 禁止让图像模型生成中文、卡片、图标或人物。
- 禁止保留原图品牌活动内容、Logo、水印、标牌或伪文字。
- 禁止使用来源或许可不明的网络照片作为最终拼贴素材。
- 禁止自由修改新青年体、固定字号、字距、卡片坐标、70% 不透明度和四色候选色板。
- 禁止给核心内容添加圆点、编号、短横线或句末标点。
- 禁止让人物、地标或高对比边缘遮挡标题、副标题和卡片正文。
- 禁止用模糊、羽化蒙版、生成式溶解或透明渐变隐藏人物肩膀、衣领、衣袖和躯干边界。
- 禁止把任何自动分割模型的一次性输出直接作为最终人物层；禁止在未做边缘去色污染的情况下交付深色衣服或头发抠图。
- 禁止让海报 y=0–688 只有天空、纯色或简单渐变；不得用噪点代替真实地点素材密度。
- 禁止背景出现贯穿式横竖接缝、矩形色块、拉丝、复制/镜像素材、重复地标、透视断裂或大面积人物移除补洞。
- 禁止把硬错误降级为警告，禁止写入未经用户当次明确表达的“用户已授权”，禁止使用本地脚本副本生成通过报告。
- 禁止在副标题上方、下方或背后加入横线、分隔线、装饰线、长条底色、暗带、亮带、蒙版或横向渐变。

## 交付

报告最终文件绝对路径、1024×1536 尺寸、背景素材类型、人物处理方式和标题实际选色；支持时以内联图片展示成品。
