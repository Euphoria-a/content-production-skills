# 事务安全与交付

## 内部目录

- 使用项目名和时间创建新的本地目录，不使用项目根、工作区根、用户主目录或磁盘根。
- 对规范化输出路径获取非阻塞内核排他锁。锁失败立即退出；强制模式不能绕过活动锁。
- 拒绝无法保证一致锁语义的网络共享路径。
- 暂存、目标和备份必须位于同一文件系统。
- 完整写入五个内部文件、事务清单和完成标记后，再校验 SHA-256、事务 ID 和母版哈希。
- 首次发布通过目录原子重命名完成；目标已有内容时默认失败。
- 只有用户明确授权覆盖具体目录时才启用强制覆盖。先整体备份旧目录，再原子发布；失败时整体恢复。
- 回滚只处理事务清单能够证明属于当前事务的路径。

内部完成目录包含五个业务文件、事务清单和完成标记。读取前必须执行事务校验，不能信任单个文件。

## 最终目录

一次任务只有一个最终成品文件夹。单集三个文件或系列全部文件直接位于该文件夹，不创建分集子目录。

单集白名单：

1. 01-音色克隆文案.txt
2. 02-智能文稿匹配文案.txt
3. 03-模块化视频脚本与分镜.xlsx

系列文件名前加“第01集-”等稳定前缀。集数不得进入文件正文、工作表名称或数据行。

最终目录禁止出现母版、源副本、Markdown、JSON、读音表、质量报告、锁、事务文件、备份或临时目录。

## 发布前核对

- 事务文件与所有业务文件属于同一事务和母版。
- source_sentence_text、字幕和分镜原文均可逐字符回拼。
- 读音替换只存在于配音文本。
- 字幕不存在空行、纯标点、超限或机械截断。
- SHOT 字段完整，时长覆盖旁白，创作细节已复核。
- 工作簿公式、条件格式、映射关系和可见 QC 通过。
- 文件数量严格等于 3 × 集数，且只有一个最终目录。

任何失败都保留内部诊断，不把残缺结果发布到最终目录。
